# RIV-003 — Evidence granularity and observability limits
Pre-execution protocol; exploratory, AI-assisted, owner review pending. No claim of external replication or product leadership.

Question: under what explicit trust assumptions can revision-aware snapshots distinguish exact-write compliance from target-state satisfaction? Extend RIV-002 without modifying OpenActionProof production code.

Model: two resources, target and neighbor, initially 0; requested exactly one target write to 1 and no other writes. Enumerate all sequences of length 0 through 4 over four events T0,T1,N0,N1 (341 histories). Apply each event as an actual model state update, including increments for same-value writes. Truth: exact sequence [T1]. Four evidence regimes: honest counters/journal; counters reset to minimal final-state deltas with journal intact; journal omitted entirely with honest counters; both counters reset and journal replaced by minimal final-state transition sequence. These intentionally adversarial regimes are not probabilities. Missing journal is not a false signature. No cryptographic verification claimed.

Methods: target final state; whole snapshot; whole snapshot plus revision vector (target revision=1, neighbor=0); exact journal with whole snapshot, abstain if journal missing. Compute confusion counts, abstention by truth, violation false acceptance, true acceptance, decision coverage, and balanced score (50% violation rejection, 30% valid acceptance, 20% coverage, where rejection excludes abstention). This deliberately weights safety; report raw counts and do not interpret as a market ranking. Equal sequence weights are not operational probabilities; only one valid history per regime. Report observation-equivalence classes that contain both compliant and violating histories for each evidence level, ignoring journal when missing. H1 honest revision and journal have zero false accepts and accept valid history; H2 target and whole snapshot have nonzero false accepts even under honest observation; H3 resetting counters breaks revision guarantee; H4 missing journal reduces coverage to zero; H5 if both evidence channels are fabricated, neither revision nor journal establishes exact-write compliance. All results including negatives will be published. This is a reference-model experiment, not a run of OAP's SQLite module or an external competitor. No live agents. Run twice, compare serialized output, check sequence count, oracle, confusion sums, and deterministic evidence.
